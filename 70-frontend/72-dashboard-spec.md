## 서론

이 문서는 대시보드의 **화면·기능 스펙**이다. 두 벌로 나뉜다:
- **본론 = MVP(v1)**: 승인이력·예측대조·데이터조회 3개 뷰. **Must~Could 대부분 구현완료**(2026-09-07~09) — 2차 프로젝트 스코프가 이거 전부다.
- **부록 = 협업 대시보드 확장(v2)**: 디자이너·마케터·SCM·경영진까지 5개 이해관계자가 함께 쓰는 확장판 청사진. **Must 티어(역할 스위처·해시태그·협업허브 UI 뼈대)만 구현**, 나머지는 2차 프로젝트 스코프 밖 백로그 — 다음 프로젝트 사이클에서 참고할 자료로만 존재한다.

## 본론 — MVP(v1) 스펙

> 관련 문서: [[22-feature-spec]] · [[83-demo-scenarios]] · [[26-deliverables]] · [[24-alert-rules]]
> **스코프 원칙**: [[22-feature-spec]] 3절 제외사항 안 어기는 선에서, 화면을 늘리지 않고 2개 뷰(승인이력·예측대조)를 깊게 만드는 방향.

### 0. 화면 구조
```
좌측 사이드바 (로고 + 역할 스위처 + 탭: 홈 | 협업 허브 | 승인이력 | 예측대조 | 데이터 조회 | 버전 기록)
├─ 승인이력 뷰 (Must) — 요약카드 4개, 필터/검색/정렬, 발주추천 테이블, 상세 드로어
├─ 예측대조 뷰 (Must) — 요약카드 3개, 기간선택기, 메인 라인차트, 카테고리별 오차율, SKU별 오차 테이블
└─ 데이터 조회 뷰 (Should) — 질문 칩 기반 셀프서비스 조회

Teams 접점 (별도 화면 아님)
├─ 필수: Power Automate → Teams Adaptive Card 승인 알림
└─ Should: 웹앱을 Teams 채널 "웹사이트" 탭으로 고정
```

### 1. 승인이력 뷰
**요약 카드(4개)**: 대기중 발주추천(`status=Pending` 수) · 오늘 승인 건수 · 반려율 · 평균 처리시간

**필터/검색/정렬**: 상태(전체/대기/승인/반려) · 카테고리(TOP/PNT/OUT/DRS/CLR/ACC) · 인기도(HERO/STEADY/NICHE) · SKU 검색 · risk_score/생성일시/추천수량 정렬. **(백로그, Could)** 라인 구분 필터(베이직/트렌드캡슐) — 필드가 이미 있어 구현비용 거의 0.

**테이블 컬럼**: SKU · 스타일명 · 카테고리/컬러/사이즈 · 인기도 · risk_score(숫자+그라데이션 바) · 예측수요 · 추천수량 · 상태 · 생성일시. 페이지당 20건.

**상세 드로어**(행 클릭): risk_score 근거 분해([[24-alert-rules]] 공식) · 재고 현황 스택바(available/reserved/safety_stock/reorder_point) · 최근 판매 스파크라인 · 승인/반려 버튼(반려 시 자유입력 사유 + 해시태그 칩 5종).

### 2. 예측대조 뷰
**요약 카드(3개)**: 검증 기간(cutoff~held-out 종료일) · 평균 오차율(MAPE) · 목표 정확도 대비 달성률([[44-kpi-definitions]])

**차트**: 기간 선택기(프리셋+커스텀) → 메인 예측-실측 라인차트(카테고리 필터 토글) → 카테고리별 오차율 바차트(계절 민감도, [[64-real-world-grounding]]) → SKU별 오차 테이블(클릭 시 메인차트 하이라이트).

### 3. 데이터 조회 뷰 (Should)
완전 자유입력 SQL 대신 **미리 정의한 질문 칩**(안전 + 저비용): "이번 주 반품 많은 카테고리는?" · "가장 위험한 SKU 5개는?" · "이번 달 채널별 매출은?" · "인기도 티어별 평균 판매량은?". 클릭 시 표/차트 자동 표시 + CSV 다운로드.

### 4. 디자인 시스템 (담당자 재량, 2026-09-09 확정)
- **컬러**: 지그재그 브랜드 팔레트 — Poppy Pink `#F33283`(accent) / Punchy Pink `#FF80B4`(hover) / Pastel Pink `#FFADD7`(soft) / White `#FFFFFF` / Off-White `#F9F9F9` / Black `#000000`(sidebar). 회색은 Black의 투명도만 사용
- **상태색**: 대기=amber/승인=green/반려=red ([[24-alert-rules]] 우선순위 색과 통일), risk_score는 단일 색조 명도 변화(색맹 접근성)
- **폰트**: Pretendard 로컬 서빙. **컴포넌트**: Tailwind CSS v4. **차트**: Recharts(→ Razor 전환 시 Chart.js 등으로 교체 필요)

### 5. 데이터 연동 (2026-09-14 확정)
프론트는 Dataverse를 직접 호출하지 않는다 — 최민님의 **C# API 서버**(`FashionAI.Api`)만 호출. 엔드포인트 계약: [[25-execution-design]] 4-2절.
| 화면 요소 | 호출 API | API 내부 동작 |
| --- | --- | --- |
| 승인이력 테이블 | `GET /api/reorders?status=` | `ReorderRecommendation` 조회 |
| 승인/반려 액션 | `PATCH /api/reorders/{skuCode}` | 레코드 PATCH |
| 예측대조 차트 | `GET /api/forecast?range=` | 예측+held-out 실측 조회(저장 방식 ML 롤과 협의 필요) |

### 6. 우선순위 구현 현황
Must(요약카드·필터·테이블·메인차트) ✅ 완료 / Should(상세드로어·오차율·데이터조회) ✅ 완료(Teams 탭 연동만 미착수) / Could(SKU오차테이블·스파크라인) ✅ 완료, Power BI·자유입력 확장은 미착수.

### 7. Teams 연동
필수(승인알림): Power Automate가 Dataverse 신규 행 감지→Teams 카드 발송. Should(대시보드 탭): Teams 채널에 웹앱 주소 등록. **데모 주의**: 심사위원은 우리 Teams 조직이 아니므로 탭을 못 봄 — 라이브 데모는 브라우저로.

| 구분 | 항목 | 상태 |
| --- | --- | --- |
| Must | 역할 스위처·해시태그 칩·협업허브 UI 뼈대 | ✅ 완료 |
