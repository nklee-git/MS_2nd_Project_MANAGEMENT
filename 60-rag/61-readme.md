> **담당 (2026-09-16 갱신, 2차)**: RAG 실행을 형준에게 이관했었으나(2026-09-16 1차 갱신), 형준이 같은 날 팀에서 이탈하면서 **나경 단독 담당으로 복귀**(9/11 이전 원래 체제와 동일). Adaptive Card + Power Automate Cloud Flow 코어는 이미 나경이 직접 구현·테스트 완료. 상세 이력은 [[62-work-order-parkhyungjun]](보관용, 더 이상 유효하지 않음) 참고.
> **담당 (2026-09-17 갱신, 3차)**: 팀 담당 체계를 역할 리드 기준으로 재정리하면서 RAG·자동화 코어(위 Adaptive Card+Flow, 나경이 PM으로서 만든 뼈대)와 실측 데이터 기반 RAG 프로토타입은 **임현제(ML·RAG·LLM 엔지니어 리드)** 소관 — 9/17 저녁 기준 이미 프로토타입 완료 보고됨.
> **담당 (2026-09-17 갱신, 4차 — 최신, 오전 3차 정정)**: [[64-work-order-genai-stretch]]는 임현제 소관이 아니라 **박형준에게 할당하려고 나경이 만든 작업지시서**였음이 확인됨 — 3차 갱신 때 "RAG는 임현제 담당"이라는 일반 원칙만 보고 넘겨짚은 오류였음, 취소. 박형준 착수 여부 불투명(간헐적 참여) — 정체 시 나경이 직접 처리할 가능성. 아래 2026-09-14 전달사항 2건의 담당자는 미확정(②는 임현제 본인 제안 아이디어라 그가 맡을 가능성이 높지만 확정 아님).
