## 폴더 구성 (2026-09-14 개편)
실행 영역별 롤이 서로 안 부딪히게 폴더 번호를 예약해둠 — 새 폴더 만들 때 아래 표부터 확인. 하위 폴더·파일 단위까지 전부 펼친 상세 표는 [[00-folder-structure-guide]] 참고.

| 번호 | 폴더 | 용도 | 담당 |
| --- | --- | --- | --- |
| 00 | `00-wbs` | 진행 관리(일정·체크리스트·회의록·일일업무일지) | 나경 |
| 10 | `10-planning` | 기획 문서(킥오프·기술조사·차별화·백로그·Dataverse 가이드) | 나경 |
| 20 | `20-architecture` | 기술 설계·확정 스펙·시각화 허브 | 최민(테크리드) |
| 30 | `30-data` | 가상 브랜드(NQNQ) 기획 문서 + 데이터 생성 스크립트 설명 | 전원 |
| 40 | `40-pipeline` | 데이터·인프라·백엔드 API 롤 | 최민 |
| 50 | `50-databricks` | ML·모델링 롤 | 임현제 |
| 60 | `60-rag` | RAG·자동화(Power Automate) 롤 | 나경 |
| 70 | `70-frontend` | 대시보드·프론트 롤 | 나경·박형준 |
| 80 | `80-presentation` | 최종 발표 슬라이드·시연 스크립트 | 나경 |
| 90 | `90-startup-grant` | 모두의창업 2기 지원(학교 프로젝트와 별개 트랙) | 나경 |

**넘버링 규칙**: 최상위 폴더는 `00,10,20...90`. 그 하위는 부모의 앞자리를 이어받아 `01,02,03...`(예: `00-wbs` 안은 `01-docs,02-checklists,03-meetings,04-daily-logs`) — 더 깊은 폴더(예: `30-data/31-nqnq-frame`)는 그 안에서 다시 `00,10,20...`으로 새 데카드를 시작함. 새 항목이 필요하면 이어지는 다음 번호를 쓰고, 완전히 새 대분류가 필요할 때만 비어있는 십진 자릿수를 새로 연다.

> ⚠️ 별도의 코드 저장소(`MS_2nd_Project_CODE`, 로컬 폴더명은 아직 `MS_2nd_Project_Team`)는 아직 이전 폴더명(`30.DATA/32. nqnq_data` 등)을 씁니다 — 실제 코드·데이터가 도는 곳이라 이번 개편 범위 밖입니다. 이 문서(기획 저장소) 안에서 그 저장소 경로를 가리키는 텍스트는 그대로 옛 이름입니다.
