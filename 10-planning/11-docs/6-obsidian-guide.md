## 1. Obsidian이 뭔가 (한 줄 요약)

마크다운(`.md`) 파일로 글을 쓰는 편집기인데, 문서끼리 서로 링크로 연결되고(`[[문서명]]`), 여러 문서에 흩어진 체크박스를 한 화면에 모아서 실시간으로 보여주는(Dataview) 기능이 있는 도구. 우리는 이 볼트 전체를 프로젝트 위키처럼 쓰고 있음.

## 2. 핵심 기능 4가지 — 이 볼트에서 쓰는 전부

### 2-1. 위키링크 `[[문서명]]`
문서 이름을 대괄호 두 개로 감싸면 그 문서로 가는 링크가 됨. 타이핑 중 `[[`까지 치면 자동완성 목록이 뜸.
- 클릭하면 해당 문서로 이동
- 같은 이름 파일이 여러 폴더에 있으면 안 헷갈리게 `[[04.MS-DataSchool/20.PROJECT/22.MS_2nd_Project/00-wbs/01-docs/1-execution-plan]]`처럼 전체 경로로 쓴 곳도 있음(이 볼트는 여러 프로젝트가 같이 있어서)
- 오른쪽 패널(백링크)에서 "이 문서를 누가 링크했는지" 역방향으로도 확인 가능

### 2-2. 문서 맨 위 요약 블록 `>`
문서 시작 부분에 `>`로 시작하는 인용 블록으로 "관련 문서"와 "용도"를 요약해둠 — 지금 이 문서 맨 위도 그 형식. 새 문서 만들 때 이 패턴 그대로 따라갈 것.

### 2-3. 체크박스 + 태그로 할일 관리 `- [ ] 내용 #todo/카테고리`
그냥 마크다운 체크박스인데, 끝에 `#todo/now`, `#todo/onboarding`, `#todo/week0`, `#todo/week1-3`, `#todo/presentation`, `#todo/backlog` 같은 태그를 붙이면 [[1-todo-board]]가 자동으로 모아서 보여줌. **원본 문서 아무 데나 이 형식으로 체크박스를 추가하면 끝** — 대시보드에 손으로 옮겨 적을 필요 없음.

### 2-4. Dataview 쿼리 — 실시간 집계
[[1-todo-board]]나 [[index|daily-logs 인덱스]] 맨 위에 있는 ` ```dataview ` 코드블록이 그 예. 지정한 폴더 안 문서들을 실시간으로 훑어서 표나 리스트로 뽑아줌. 우리는 이 두 종류만 씀:
- `TABLE` — 문서별 통계 요약 (예: 문서당 남은 할일/완료 할일 개수)
- `TASK` — 태그로 필터링한 체크박스 목록

**이 쿼리들을 보려면 Dataview 플러그인 설치가 필수**(4절 참고) — 안 하면 저 코드블록이 그냥 텍스트로만 보임.

## 4. 설치해야 하는 것 — Dataview 플러그인 (필수)

1. Obsidian 설정(왼쪽 아래 톱니바퀴) → Community plugins
2. "Restrictions 해제"가 안 돼 있으면 켜기 (Community plugin 설치 허용)
3. Browse → 검색창에 "Dataview" → 설치(Install) → 활성화(Enable) 토글 ON
4. **Obsidian 완전 재시작** (이거 안 하면 반영 안 될 때 있음)
5. 확인: [[1-todo-board]]를 열었을 때 표/체크박스 목록이 실제로 보이면 성공. 코드처럼 회색 박스로 텍스트만 보이면 설치 안 된 것

## 5. 기본으로 켜져 있는 유용한 패널

아래는 별도 설치 없이 Obsidian 자체에 내장된 기능(이 볼트에서 켜둔 것):
- **백링크(Backlinks)** — 오른쪽 패널, 지금 보는 문서를 누가 링크했는지
- **그래프 뷰(Graph view)** — 문서 전체가 어떻게 링크로 얽혀있는지 시각화
- **페이지 미리보기** — 위키링크에 마우스 올리면(호버) 그 문서 내용 미리보기
- **아웃라인(Outline)** — 지금 문서의 제목(헤딩) 구조를 목차처럼 보여줌

## 6. 새 문서 쓸 때 지킬 것

- 맨 위에 `> 관련 문서: ...` / `> **용도**: ...` 요약 블록 먼저 쓰기(2-2절)
- 폴더/파일 번호는 [[00-folder-structure-guide]] 규칙부터 확인 — 아무 번호나 붙이지 말 것
- 할일이 생기면 원본 문서에 바로 `- [ ] ... #todo/카테고리`로 적기 — 대시보드에 따로 옮기지 않아도 됨
